**Type:** Single Choice

### Question
Which IP type protects software code?

### Options
- A. Patent
- B. Copyright
- C. Trademark
- D. Trade Secret

### Correct Answer
B. Copyright

### 💡 Hint
Think about which IP right protects original works such as source code and documentation.

### Explanation
Copyright protects software code, documentation, and other original works.

### Why Other Answers Are Wrong
- A. Patent → protects inventions, technologies, and processes.
- C. Trademark → protects brand names, logos, and distinctive identities.
- D. Trade Secret → protects confidential information kept non-public; the lecture’s direct mapping for software code is copyright.

### ⚫ Trap
Do not assume “software = technical = patent.”
